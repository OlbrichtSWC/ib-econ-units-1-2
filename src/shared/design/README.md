# Design system

School colours: royal blue `#1D4ED8`, red `#C8102E` and white, with light blue tints. (The CSS variables are still called `--navy` for history.) Chunky buttons, a dotted background, a royal blue banner and coloured card edges (blue for Unit 1, red for Unit 2) give the playful look. Headings in Fredoka, body in Nunito (both stored in `fonts/`, SIL Open Font License), then Calibri and the system sans-serif.
All text colours meet WCAG AA contrast. `tokens.css` holds colours, type and components (buttons, cards, badges, tabs, callouts, dialogs, tables, projector mode).
`components.tsx` holds small shared components (badges, mark and cross icons, dialogs, live region).
