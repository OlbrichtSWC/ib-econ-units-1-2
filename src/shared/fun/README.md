# Fun: celebrations and stamps

- `celebrate.ts`: `celebrate()` or `celebrateAt(button)` shows a confetti burst. Mount `CelebrationLayer` once in the app.
- `Stamp.tsx`: the rubber-stamp picture used in the stamp book. `StampToast` announces a new stamp.
- `motion.ts`: `reducedMotion()` is true when the device asks for less motion. Animations are skipped then.

Rules: no leaderboards, no timers, no streaks. Stamps are personal and are never taken away.

Needs: `design/`.
